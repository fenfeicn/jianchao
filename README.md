# 剪巢

**复制有处收，常用随手取。**

一个原生 macOS 菜单栏剪贴板工具。把复制过的文字、图片和文件引用留在本机，需要时搜一下，选中，再粘贴到原来的输入位置。

[下载安装包](https://github.com/fenfeicn/jianchao/releases/latest) · [反馈问题](https://github.com/fenfeicn/jianchao/issues) · [MIT 许可证](LICENSE)

## 它能帮你做什么

- 找回被下一次复制覆盖的文字，不用再回浏览器或聊天记录里翻。
- 看图片缩略图和大预览，也能打开独立窗口放大。
- 通过关键词、类型、日期和收藏筛选历史。
- 在长文本预览里查找关键词，配合行号确认位置。
- 用全局快捷键呼出，回车直接粘贴，或仅复制后自己粘贴。
- 自己决定历史留多久、最多留多少、使用多少本地空间。

无需账号，没有云同步，不自动上传剪贴内容。

## 下载与安装

打开本仓库的 [Releases 下载页](https://github.com/fenfeicn/jianchao/releases/latest)，下载 **Jianchao-0.3.6-universal.dmg** 即可，无需下载或编译源码。

1. 打开 DMG，将「剪巢」拖入「应用程序」。
2. 推出安装镜像，从「应用程序」启动剪巢。
3. 阅读首次说明，点击「开始记录」。
4. 需要直接粘贴时，按「设置 → 通用」引导开启相关系统权限。

当前安装包未完成 Apple 公证。首次打开可能被系统拦截；确认来自可信下载入口后，按系统提示前往「系统设置 → 隐私与安全」允许打开，无需关闭系统整体安全检查。

剪巢常驻菜单栏，不显示 Dock 图标。升级前请退出旧版，替换应用后再启动，避免同时运行多个副本。

## 一分钟上手

在编辑器里先点好准备输入的位置，按 **⌥⌘V** 呼出剪巢，搜索或选中一条内容，按 **回车**。

| 操作 | 快捷键 |
| --- | --- |
| 呼出 / 关闭面板 | ⌥⌘V，可在设置中修改 |
| 上下选择 | ↑ / ↓ |
| 直接粘贴 | Return |
| 只复制，不粘贴 | ⌘Return |
| 使用当前结果前九条 | 面板打开后按 ⌘1–9 |
| 收藏 / 取消收藏 | ⌘D |
| 查找当前文本预览 | ⌘F |
| 下一个 / 上一个匹配 | ⌘G / ⇧⌘G |
| 放大图片 | ⌘Y |
| 设置 | ⌘, |
| 关闭查找 / 面板 | Esc，逐层关闭 |

查找展开时，回车用于跳转匹配。前九条快捷键对应当前搜索、筛选后的列表顺序。

直接粘贴需要系统允许相关控制和按键发送权限；不同版本入口可能称为「辅助功能」或「设备控制和数据访问」。如果升级后旧权限条目失效，按应用引导定位当前安装的剪巢，移除旧条目并重新添加，再重启。仅复制不需要直接粘贴权限。

## 图片、文件与历史保留

其他应用复制的单张图片会优先保存可读取的图片数据或本地快照；Finder 和多文件记录保留原文件引用，原文件被移动、删除后旧引用可能失效，不能视为文件备份。

新安装默认保留 **30 天 / 5,000 条 / 500 MB**，可在设置中调整。「不按时间清理」仍受条数和空间上限约束。收藏不会按普通历史的时间规则自动过期；收藏占满预算时停止新增，不自动删除收藏。

## 隐私

当前数据存储在本机 `~/Library/Application Support/Jianchao/`，为**明文存储**。没有自动敏感应用排除或全量敏感信息识别。需要时请暂停记录，或使用「跳过下一次复制」。

锁屏时暂停；暂停期间的内容不会补录。删除历史不会清空当前系统剪贴板，也不能清除系统备份里的副本。

## 系统要求

- 部署目标：macOS 14 及以上。
- 安装包包含 Apple Silicon 与 Intel 两种架构。
- 已完成当前设备实机验证：macOS 27、Apple Silicon。
- macOS 15、26 及 Intel 设备尚待更多实机验证。部署目标和通用构建不代表所有设备已经测试。

## 从源码构建

项目使用 Swift、SwiftUI、AppKit 和 SQLite，采用 Swift Package Manager，无需额外的第三方依赖。

当前使用 macOS 27 和 Swift 6.4 Command Line Tools 构建；旧系统运行兼容性不代表旧版本 SDK 可以直接编译当前源码。

```sh
./scripts/build-app.sh
```

应用输出到 `build/剪巢.app`。独立演示模式不会读取或更改真实剪贴板：

```sh
open -n build/剪巢.app --args --demo
```

项目需要的图标等运行资源已包含在源码内。开发者首次配置本地签名后，请保留本机 `.build/signing`；其中的私钥、钥匙串和密码不得提交。其他设备应创建自己的开发身份。
